## 👨‍💻 Cybersecurity Projects

A connected, hands-on portfolio built entirely on a resource-constrained home lab — each project builds on the last, from a segmented enterprise network to a SIEM watching it, a honeypot feeding that SIEM, malware analyzed safely, and finally CTF challenges that exploit and get *detected* by the same infrastructure.

### 🔹 [Build a Network (Virtual Lab)](https://github.com/ayoubkhachane/Network-Lab)
A simulated enterprise network with pfSense, Active Directory, and segmented VLANs enforcing real access control between zones.

### 🔹 [Build a SIEM](https://github.com/ayoubkhachane/SIEM-Lab)
Deployed Wazuh to collect and analyze security logs across the network — including working through and documenting a real installer-bug debugging saga before pivoting to Wazuh's official deployment method.

### 🔹 [Build a Honeypot](https://github.com/ayoubkhachane/Honeypot-Lab)
Deployed a Cowrie SSH/Telnet honeypot to capture real attacker behavior, with custom Wazuh detection rules written specifically for its non-standard log format.

### 🔹 [Malware Analysis](https://github.com/ayoubkhachane/Malware-Analysis)
Manual static and dynamic malware analysis in a fully isolated lab — from a safe EICAR baseline up to analyzing a real RAT sample (njRAT) with PE Studio, Process Monitor/Explorer, and Wireshark.

### 🔹 [Create CTF Challenges](https://github.com/ayoubkhachane/CTF-Challenges)
Five self-designed challenges (web, reverse engineering, crypto, forensics, scripting) — with the web challenge deliberately networked and exploited live, then detected in real time by the Wazuh SIEM above, closing the loop between offense and defense.

### 🔹 [Cyber Tools & Scripts](https://github.com/ayoubkhachane/CyberTools)
Automation built directly from the manual work above: a Wazuh alert digest, a custom-rule generator, and a pfSense firewall auditor that automatically flags the exact misconfiguration patterns that cost the most debugging time across this whole portfolio.
